# Configuration map

هذه المجلدات هي نقطة التعديل الأساسية، ولا تحتاج المشاريع المستهلكة إلى مراجعة ملفاتها عند تغيير الإعدادات.

| الحاجة | عدّل الملف | ما الذي يتغير |
| --- | --- | --- |
| إضافة أو حذف مزود | `providers.json` | تعريف المزود وkind وbase URL ومجموعة المفاتيح |
| إضافة أو حذف نموذج | `models.json` | النموذج ومكانه في chain وترتيب الأولوية |
| تغيير أسماء الأسرار أو مجموعات المفاتيح | `key_pools.json` | متغير البيئة الذي يقرأ المفاتيح |
| تعديل التبريد والـ backoff والحد الأقصى للمحاولات | `policies.json` | سلوك retry والفشل |

قيمة API key الحقيقية لا توضع هنا. تبقى في GitHub Secrets أو متغير بيئة محلي باسم المجموعة المعرفة في `key_pools.json`.
